# MiniMax 语音

用 MiniMax 把文字读出来。播客和白板里的文字转语音都可以用它，还能挑选音色，或者用一段录音复刻出想要的声音。

## 开始使用

1. 在插件中心安装「MiniMax 语音」，再到插件页的「已安装」里打开它的开关，马上就能用，不用重启。
2. 打开「设置 → 语音 → 语音合成」，添加一个 MiniMax 账号，填写 API Key、服务地址和模型。
3. 保存后选择默认的账号、模型和音色，之后播客和白板里的朗读都会用它。

可以添加多个账号，各自保存自己的设置。

## 复刻声音

上传一段清晰的录音，就能复刻出一个新音色，也可以一次复刻多个。录音直接交给 MiniMax，不需要另外设置上传方式。

## 常见问题

**取消了还会扣费吗？** 可能会。取消只是不再等待结果，MiniMax 那边已经完成的合成或复刻仍可能计费。

## 小提醒

- 需要 Tau 0.59.0 或更高版本。
- 合成语音、复刻声音和重试都会消耗 MiniMax 的额度。
- API Key 不要发给别人，也不要贴在截图或问题描述里。
