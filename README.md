# MiniMax 语音

提供语音合成、音色查询和声音复刻。可在 Tau 的语音设置中添加多个独立账号，分别保存 API Key、服务地址与模型。

需要支持 TTS 插件的 Tau 客户端。安装启用后，在「语音 → 语音合成」添加 MiniMax 语音账号，保存凭据和模型，再选择默认账号、模型和音色。播客与白板文本转语音使用该选择。

每个复刻音色使用一个清晰的参考音频文件，可批量创建多个音色；复刻直接提交 MiniMax，无需公开图床。最终音色以返回 ID 为准。合成、复刻和重试可能消耗服务商额度；取消不会撤回已完成的服务端请求。

源码使用 TypeScript，pnpm 管理依赖。执行 pnpm test、pnpm build 生成 dist 下的 ZIP。MIT 许可。
