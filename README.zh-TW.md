# MiniMax 語音

使用 MiniMax 進行語音合成，把文字朗讀出來。Podcast 與白板中的文字轉語音都能使用它，還能挑選音色，或上傳一段錄音複刻想要的聲音。

## 開始使用

1. 在外掛中心安裝「MiniMax 語音」，再到外掛頁的「已安裝」中開啟開關，立即生效，無需重新啟動。
2. 開啟本外掛詳情的「設定」，新增一個 MiniMax 帳號，填寫 API Key、服務位址與模型。
3. 儲存後，在應用程式「設定 → 語音」（手機為「我的 → 語音」）中選擇預設的帳號、模型與音色，之後 Podcast 與白板中的朗讀都會使用它。

可新增多個帳號，各自保存獨立設定。設定完成後可先試聽一段文字確認帳號可用；試聽不會改變你選好的預設語音。

## 複刻聲音

上傳一段清晰的錄音，就能複刻出一個新音色，也可以一次複刻多個。錄音會直接傳送給 MiniMax，不需另外設定上傳方式。

## 常見問題

**取消後還會扣費嗎？** 可能會。取消只是不再等待結果，MiniMax 端已經完成的語音合成或聲音複刻仍可能計費。

## 小提醒

- 語音合成、複刻聲音與重試都會消耗 MiniMax 的額度。
- 請妥善保管 API Key 金鑰，切勿傳給他人，也不要貼在截圖或問題描述中。
